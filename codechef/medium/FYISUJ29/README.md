## Problem

### Video Rating Tracker

Write a program to  **track the average rating**  of a video on a video-sharing platform using the  **float data type**  to store decimal values.

 **Steps to Complete:** 

- Declare a float variable named currentRating to store the current rating.
- Declare another float variable named maxRating for the maximum possible rating.
- Print both values to verify they are correctly stored.

 **Expected Output:** 
If stored and printed correctly, your output should look something like:

```
Current Video Rating: 4.7  
Maximum Possible Rating: 5.0  

```

Run the code, modify values, and test different rating scenarios!

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-06T06:22:11.906Z  

```java
class Codechef {
    public static void main(String[] args) {
        // Step 3: Declare and assign rating values
        float currentRating = 4.7f;  // Current rating of the video
        float maxRating = 5.0f;  // Maximum possible rating
        // Step 5: Print the ratings
        System.out.println("Current Video Rating: " + currentRating);
        System.out.println("Maximum Possible Rating: " + maxRating);
    }
}

```

## Problem

### Performing Multiplication

In this example, we demonstrate how to declare integer variables, multiply values, and print the result in Java. The multiplication operator (`*`) allows us to perform calculations efficiently and store the results for later use.

 **When executed, the code will show:** 

```
Multiplication result: 18

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-06T09:20:44.526Z  

```java
class Codechef {
    public static void main(String[] args) {
        // Declare and initialize two integer variables
        int num1 = 6;  // First number
        int num2 = 3;  // Second number

        // Perform multiplication and store the result
        int product = num1 * num2;

        // Print the product value
        System.out.println("Multiplication result: " + product);
    }
}
```

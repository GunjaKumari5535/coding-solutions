## Problem

### Performing Division Using the Division Operator

In this example, we demonstrate how to declare integer variables, perform division, and print the result in Java. The division operator (`/`) allows us to compute the quotient efficiently.

 **When executed, the code will show:** 

```
Result: 6

```

**Runtime:** N/A

```java
class Codechef {
    public static void main(String[] args) {
        // Declare integer variables
        int num1 = 25;
        int num2 = 4;
        int result; // Declare result variable

        // Perform division and store the result
        result = num1 / num2;

        // Print the result
        System.out.println("Result: " + result);
    }
}
```

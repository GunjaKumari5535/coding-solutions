## Problem

### Performing Subtraction

In this example, we demonstrate how to declare integer variables, perform subtraction, and print the result in Java.
The subtraction operator (`-`) allows us to compute the difference efficiently.

 **When executed, the code will show:** 

```
Difference: 20

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-06T09:17:03.901Z  

```java
class Codechef {
    public static void main(String[] args) {
        // Perform subtraction and store the result
        int num1 = 25;
        int num2 = 5;
        
        int difference = num1 - num2;

        // Print the result
        System.out.println("Difference: " + difference);
    }
}

```

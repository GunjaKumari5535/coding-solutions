## Problem

### Floating-Point Division in Java

What will be the output of the following Java program?

```
class Codechef {
    public static void main(String[] args) {
        double result = 9.0 / 4;
        System.out.println("Result: " + result);
    }
}

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-06T09:30:55.077Z  

```cpp
class Codechef {
    public static void main(String[] args) {
        // Declare two floating-point variables to store scores
        double score1 = 85.5;
        double score2 = 90.0;
        
        // Perform floating-point division to calculate the average
        double average = (score1 + score2) / 2;
        
        // Print the calculated average
        System.out.println("Average Score: " + average);
    }
}
```

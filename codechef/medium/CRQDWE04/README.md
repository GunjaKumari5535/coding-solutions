## Problem

### Using the Addtion Operator

What will be the output of the following Java program?

```
class Codechef {
    public static void main(String[] args) {
      
        int num1 = 5;
        int num2 = 10;
        int num3 = 15;
        int sum; 
        sum = num1 + num2 + num3;

        System.out.println(sum);
    }
}

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-06T09:15:47.292Z  

```cpp
class Codechef {
    public static void main(String[] args) {
        // Declare integer variables
        int num1 = 10;
        int num2 = 5;
        int sum; // Declare sum variable

        // Perform addition and store the result
        sum = num1 + num2;

        // Print the result
        System.out.println("Sum: " + sum);
    }
}

```

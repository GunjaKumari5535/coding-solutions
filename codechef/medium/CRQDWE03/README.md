## Problem

### Performing Addition

In this example, we demonstrate how to declare integer variables, perform addition, and print the result in Java. The addition operator (`+`) allows us to compute the sum efficiently.

 **When executed, the code will show:** 

```
Sum: 15

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-06T09:15:34.731Z  

```java
class Codechef {
    public static void main(String[] args) {
        // Declare integer variables
        int num1 = 10;
        int num2 = 5;
        int sum; // Declare sum variable

        // Perform addition and store the result
        sum = num1 + num2;

        // Print the result
        System.out.println("Sum: " + sum);
    }
}
```

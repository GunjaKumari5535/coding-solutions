## Problem

### Worked Example - Updating Score

In this example, we demonstrate how to declare an integer variable, use the addition assignment operator (`+=`) to update its value, and print the result. The `+=` operator allows efficient value updates without repetitive code.

 **When executed, the code will show:** 

```
Updated Score: 70

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-06T09:46:47.658Z  

```java
class Codechef {
    public static void main(String[] args) {
        int score = 50; // Initial score

        // Updating score using += operator
        score += 20;

        // Printing the updated score
        System.out.println("Updated Score: " + score);
    }
}
```

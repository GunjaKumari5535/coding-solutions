## Problem

### Division Operator

What will be the output of the following Java program?

```
class Codechef {
    public static void main(String[] args) {
        int num1 = 50;
        int num2 = 8;
        double result = num1 / num2;
        System.out.println("Result: " + result);
    }
}

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-06T09:24:30.468Z  

```cpp
class Codechef {
    public static void main(String[] args) {
        // Declare integer variables
        int num1 = 25;
        int num2 = 4;
        int result; // Declare result variable

        // Perform division and store the result
        result = num1 / num2;

        // Print the result
        System.out.println("Result: " + result);
    }
}


```

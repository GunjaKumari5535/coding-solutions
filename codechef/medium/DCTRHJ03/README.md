## Problem

### Worked Example - Storing User Information

In this example, we demonstrate how to declare and initialize a String with values representing user details in Java. This method allows efficient storage and retrieval of text data.

 **When executed, the code will show:** 

```
Username: JohnDoe
User Status: Active User

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-07T08:08:55.526Z  

```java
class Codechef {
    public static void main(String[] args) {
        // Declaring and initializing the username
        String username = "JohnDoe";
        String userStatus = "Active User";
        
        // Printing the stored values
        System.out.println("Username: " + username);
        System.out.println("User Status: " + userStatus);

    }
}
```

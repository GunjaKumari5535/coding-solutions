## Problem

### Worked Example - Storing Gravitation Value

In this example, we demonstrate how to declare a `double` variable, assign a value, and print it.

 **When executed, the code will show:** 

```
Gravitational Acceleration: 9.80665 m/(s*s)

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-06T06:25:23.822Z  

```java
class Codechef {
    public static void main(String[] args) {
        //  Declare and assign precise gravitational acceleration value
        double gravityAcceleration = 9.80665;  // Earth's gravity in m/s² with high precision

        //  Print the value
        System.out.println("Gravitational Acceleration: " + gravityAcceleration + " m/(s*s)");
    }
}

```
